## 🟢 Course 1: AI for Everyone(DeepLearning.AI)

### Module 1: What is AI?
*   **The Supervised Learning Pipeline:** Maps raw inputs `(A)` to precise targets `(B)`. Traditional logic uses hardcoded rules; ML computes the functions automatically.
*   **Neural Network Architecture:** Stacks individual node computations into hidden layers to automate feature abstraction (e.g., mapping raw image pixel arrays down to distinct edge and object identifications without manual coding rules).
*   **The Core Engineering Takeaway:** The developer supplies high-quality, labeled mapping data `(A ➔ B)`. The learning algorithm independently iterates to calculate what processing rules each hidden layer node must compute.
